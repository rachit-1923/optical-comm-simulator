# Optical Communication End-to-End System Simulator

This is an academic engineering project simulating an optical communication channel, including laser rate equations, digital modulation, fiber attenuation/dispersion, EDFA amplification, and signal recovery.

## How to Run the Dashboard on GitHub / Streamlit Cloud

1. Upload this entire folder to a new public or private GitHub repository.
2. Go to [Streamlit Community Cloud](https://streamlit.io/cloud) and log in with your GitHub account.
3. Click "New app", select your repository, and set the Main file path to `dashboard.py`.
4. Click **Deploy**. Streamlit will automatically install the dependencies from `requirements.txt` and launch your dashboard live on the web!

## Local Development (Optional)
```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
